# Rudransh Mishra — Personal Portfolio

An ultra-luxury, high-performance personal developer portfolio built with Next.js 16 (App Router, Turbopack), React 19, SCSS Modules, and an interactive 3D futuristic cybernetic background engine.

Inspired by premium editorial and aesthetic design, featuring high-contrast luxury serif typography (`Cormorant Garamond`), modern geometric sans (`Plus Jakarta Sans`), and monospace technical detailing (`Fira Code`).

---

## ⚡ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (Turbopack, App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: SCSS Modules (BEM architecture, luxury dark aesthetic `#070709`)
- **Graphics & 3D**: HTML5 Canvas 3D Projection Engine (synaptic cybernetic network, dual gyroscopic quantum rings, interactive stardust particle field)
- **Smooth Motion & Physics**: Lenis smooth scroll & custom fluid LERP interpolation
- **Icons**: Lucide React & Custom Monochromatic SVG Vectors

## 🛠️ Getting Started

### Prerequisites

- Node.js 18.18+ (Node 20+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Rudransh-mi27/rudransh_portfolio.git

# Navigate into project directory
cd rudransh_portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Start production server
npm run start
```
